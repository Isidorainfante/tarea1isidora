# Los españoles tiran cada vez menos comida por la subida de los precios, el táper y el compromiso social

https://elpais.com/masterdeperiodismo/master2025/2025-08-13/los-espanoles-tiran-cada-vez-menos-comida-por-la-subida-de-los-precios-el-taper-y-el-compromiso-social.html

Esta nota aborda cómo en España ha disminuido el desperdicio de alimentos en los últimos años, centrándose principalmente en los hábitos de los hogares. Este suceso se construye a partir de datos concretos, por ejemplo, el desperdicio bajó cerca de un 21% desde 2020. 
El texto explica que esta disminuición no responde solo a una causa, sino a una combinación de factores: el aumento del precio de alimentos, cambios en las rutinas, entre otras. 

Me resulta interesante porque toca un tema cotidiano, el tirar comida, conviertiéndose en una historia con dimensión social, económica y cultural.

La nota está sustentada con datos duros, un desarrollo explicativo, uso de ejemplos concretos. Encontrando un equilibrio entre datos y narrativa. 

El texto es efectivo para transmitir infomación. Los datos están bien explicados y contextualizados, otorgándole creadibilidad.
